# Read the "Installing on another machine" section of README.md before copying this verbatim.
# Three things here are not what they look like:
#
#   * mcp==1.25.0 is load-bearing, not incidental. mcp 2.x renamed FastMCP to MCPServer and
#     changed the decorator/run API; installing "mcp>=1.0.0" resolved 2.3.0 on a clean venv
#     and the server could not even be imported. pyproject.toml therefore pins mcp<2.
#   * torch==2.11.0.dev20260118+cu128 is a NIGHTLY. Nightly builds are pruned from the index, so this exact pin
#     stops being installable; use a current nightly or a stable release. Verified on a clean
#     venv with torch 2.14.1+cpu: 32/32 tests and a real transcription (707 notes, device cpu).
#   * tensorflow*, torchaudio and torchcodec belong to other experiments and are NOT needed by
#     the tools. tensorflow (pulled in by basic-pitch) is what holds numpy at 1.23.5 and scipy
#     at 1.10.1 here - onnx once dragged numpy 2 in and broke both with "_ARRAY_API not found".
#     A clean venv installed without them resolves numpy 2.4.6 / scipy 1.17.1 and the tools work.
#
# Excluded from this list, both editable installs with git URLs:
#   -e git+https://github.com/kardelw1409/mcp-stem-splitter.git@...  (this project - install it
#      from your checkout: pip install -e .)
#   -e git+https://github.com/xavriley/ADTOF-pytorch@...            (obsolete: the four modules
#      and the weights now ship inside mcp_stem_splitter/vendor/adtof_pytorch and are used from
#      there, so the clone is not needed to run anything)
